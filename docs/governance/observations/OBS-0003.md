## Fact

Development HQ DevKit Issue 0001("Development HQ DevKit 최소 기능")을
Development HQ 기존 함수만으로 Planning → Design → Validation까지
실행한 결과, `design_agent_design(issue, requirement)`에 Context가
섞이지 않은 원본 `issue`를 인자로 넘겼음에도 `[Relevant Context]` 절이
`design` 산출물에 그대로 나타났다(`requirement` 문자열을 통해 전달됨).
Validation 함수(`backend_agent_code_review`, `qa_agent_test_execution`)는
Issue나 Context dict를 인자로 전혀 받지 않았지만, `design` 문자열에
남아있던 Context로 인해 `code_review`가 반환한 8건의 findings 중 7건이
"줄이 100자를 초과합니다"였다. 동일한 패턴(워크플로우 인자 전달 경로와
무관하게 상위 Artifact 텍스트를 통해 Context/Artifact가 하위 Stage까지
그대로 전달됨)이 MVP-0006, MVP-0007, MVP-0008, 이번 DevKit Issue 0001까지
총 4개의 서로 다른 실행에서 반복 관찰되었다.
