# ADC-0002: Task Dispatcher 승격 재판단 (RFC-0002 후속)

## 목적

RFC-0002에서 제기된 Task Dispatcher Boundary Question에 대해 승격 여부만
판단한다. 이 문서는 Architecture Decision Candidate이며, 구현 방법을
논의하지 않는다.

근거는 `docs/02_rfc/RFC-0002-task-dispatcher-boundary.md`,
`docs/01_mvp/MVP-0002-observation.md`, `docs/governance/adc/ADC-0001.md`,
`docs/governance/rt/RT-0001.md`로 한정한다. RFC-0002가 배경 설명으로 인용한
`development-hq/MVP.md`는 MVP-0001의 배경 참고로만 취급하며, 이 판단의 새
근거로 사용하지 않는다.

---

## Candidate

Task Dispatcher

## MVP Observation

`docs/01_mvp/MVP-0002-observation.md`에서 실제로 기록된 사실만 인용한다.

- Workflow Branch 1개가 실제로 구현되었다(`development-hq/mvp/workflow_0002.py`의
  `if`/`else` 조건 분기).
- 두 실행 경로(이슈 있음 → `test_execution` 실행 / 이슈 없음 →
  `test_execution` 생략)가 모두 실제로 실행되어 확인되었다.
- 기존 MVP-0001 테스트 3건은 모두 통과했다(회귀 없음).
- Implementation Stop Trigger(조건문이 파서/설정 파일로 대체되려는 순간)는
  발생하지 않았다.

## RFC Boundary Summary

RFC-0002는 이 Observation을 근거로 다음을 질문했다: Workflow Branch가 실제
발생한 지금 Task Dispatcher가 MVP 범위에 남아야 하는지, Trigger 충족과
ADC-0001 전제 붕괴가 같은 의미인지, 몇 개의 분기부터 하드코딩이 무너지는지,
그리고 이 분기가 MVP-0001의 Out of Scope 선언과 어떤 관계인지. RFC-0002는
이 질문들에 답하지 않았다.

## Decision

**Keep in MVP**

## Decision Rationale

MVP-0002에서 실제로 관찰된 사실은 다음과 같다: Workflow Branch 1개가
구현되었고, 두 실행 경로가 모두 실제로 실행되었으며, 기존 테스트는 모두
통과했고, Stop Trigger는 발생하지 않았다. 이 관찰 범위(분기 1개) 안에서
하드코딩된 순차/분기 호출은 끝까지 무너지지 않았다. 승격을 정당화할
Stop Trigger 발생이나 테스트 실패가 관찰되지 않았으므로, ADC-0001의 판단을
바꿀 근거가 없다.

## Risks

이번 관찰은 Branch가 하나뿐이라 판단 근거가 아직 제한적이다. 이 결정을
유지할 경우, "분기 1개에서 통했다"는 사실이 여러 분기·중첩 분기에서도
동일하게 통한다는 근거로 확장 해석될 위험이 있다.

## Next Step

No ADR Required

## Self Review

- Observation만 사용했는가 — **Pass**. `MVP-0002-observation.md`에 실제로
  기록된 4가지 사실(분기 1개 구현, 두 경로 실행, 기존 테스트 통과, Stop
  Trigger 미발생)만 근거로 사용했다.
- Candidate가 하나뿐인가 — **Pass**. Task Dispatcher만 다뤘다.
- 구현을 설명하지 않았는가 — **Pass**. Dispatcher 구현/Parser/Runtime/
  Scheduler/Memory/Registry/API/Interface/Config를 설명하지 않았다.
- Architecture Drift가 없는가 — **Pass**. 새 Layer/Component/Service/
  Baseline 없음.
- Kernel Leak가 없는가 — **Pass**. "승격한다/유지한다/보류한다" 외 구현
  암시 표현을 사용하지 않았다.
- RFC-0002와 모순되지 않는가 — **Pass**. RFC-0002가 답을 유보한 질문들에
  대해 이 ADC가 Observation 범위 안에서만 판단을 내렸고, RFC-0002가 다루지
  않은 다른 Candidate(Engine Gateway/Registry/Context 전달)는 언급하지
  않았다.
