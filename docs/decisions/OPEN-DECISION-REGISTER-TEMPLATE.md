## 작성 제한

- 최종 결정을 내리지 않는다.
- Status는 추적 상태로 사용한다.
- ADR 예약 번호는 다른 의사결정 건에 재사용하지 않는다.
- Open Decision은 Architecture Baseline에 포함하지 않는다.
