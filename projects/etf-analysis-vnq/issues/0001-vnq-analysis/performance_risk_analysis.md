**Risk profile / relevant risk factors.** REITs as an asset class carry a distinctive combination of risk drivers, and it's worth naming them since the standard equity/bond toolkit is a poor fit here: they are equity securities but with cash flows tied to real property, so they typically exhibit meaningful interest-rate sensitivity — rate moves affect both the cost of leverage/financing for the underlying REITs and capitalization rates used to value real estate assets, which in turn affects share prices. This is distinct from single-company idiosyncratic risk (as with individual stocks), credit/maturity risk (as with bonds), or commodity price risk (as with gold). However, I want to be explicit that this description of interest-rate sensitivity is general, well-known knowledge about the REIT asset class — the source data provided for VNQ does not itself quantify this sensitivity (no duration-equivalent figure, no rate-beta, no scenario analysis). It should be read as context for interpreting the asset class, not as a data-derived finding about this specific fund.
