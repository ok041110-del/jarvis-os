## Income Profile Analysis: SPDR Gold Shares (GLD)

**Distribution: None.** Based on the data provided, GLD pays no dividend or distribution of any kind. This is not a data gap — the source describes it as a structural feature of the fund. GLD holds physical gold bullion, and physical gold does not generate interest, dividends, or any other form of income. Because the trust has no underlying income stream to pass through to shareholders, there is nothing for it to distribute. Any return to an investor in this fund would come solely from changes in the price of gold itself, not from periodic cash distributions.

**Yield and payment frequency: Not applicable.** Metrics that would normally anchor this kind of analysis — a distribution yield, a payment schedule (monthly, quarterly, etc.), a distribution growth trend — do not exist for GLD according to the data given. I want to be explicit about this rather than imply a figure: there is no yield to report and no frequency to report, because there is no distribution. It would be inaccurate to describe GLD's "yield" in the way one would for an income-oriented ETF like SCHD or a bond fund like AGG; the concept simply doesn't apply here.

**Inconsistency in reported figures.** The data does flag one inconsistency, though it concerns total return rather than distribution yield: YTD performance is reported differently across sources — +2.17% on a dividend-reinvested basis in one source versus -5.42% in another. Since GLD pays no dividend per the same dataset, a "dividend-reinvested" figure for this fund is itself a discrepancy worth noting. I'm not able to reconcile these two numbers or determine which is correct from the data provided, so I'm presenting both as given rather than selecting one.

**Data limitations.** This analysis is based on a snapshot of web-search data collected as of 2026-08-16, not live pricing. The dataset does not include volatility, beta, duration, or an explicit tracking-error figure, so no statement can be made about those dimensions. This information should not be treated as a basis for investment decisions, and I'm not offering a buy/sell view here — only a description of what the income-related data does and does not show.
