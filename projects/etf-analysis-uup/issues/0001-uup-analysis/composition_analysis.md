## Composition and Index-Tracking Analysis: Invesco DB US Dollar Index Bullish Fund (UUP)

**What the fund tracks — and an unresolved discrepancy in the source data**

UUP is designed to track the Deutsche Bank Long USD Currency Portfolio Index (Excess Return version). However, the descriptive data collected here contains two materially different characterizations of what that index actually does, and this analysis will not resolve that conflict by picking one:

One source describes the benchmark as a rules-based index composed solely of long positions in USDX (U.S. Dollar Index) futures contracts traded on ICE Futures U.S. — i.e., exposure achieved through a single futures contract that itself references a fixed basket.

A second source describes the fund as replicating dollar strength against a basket of six currencies (euro, yen, pound, Canadian dollar, Swedish krona, Swiss franc) via futures positions taken in those individual currencies — i.e., exposure built from multiple separate currency futures rather than one consolidated USDX future.

These are not equivalent mechanisms. A single-instrument USDX futures replication and a multi-instrument, per-currency futures replication can behave differently with respect to roll timing, liquidity in each leg, and how precisely the fund's return matches the referenced basket's return. Because the provided data does not clarify which description is accurate — or whether both apply at different points in the fund's history — this should be treated as an open inconsistency in the record rather than a resolved fact.

**Structural implications of the fund's construction**

Regardless of which description is correct, the fund is built as a futures-based structure rather than one holding physical currencies or spot FX directly. Two features of this construction are relevant to how the fund's returns can behave:

- *Legal and tax structure*: UUP is organized as a commodity pool and, legally, a limited partnership. This affects tax reporting mechanics for holders (K-1/K-3 forms rather than 1099s) — a structural feature distinct from, but related to, the fund's investment mechanics.

- *Collateral and return composition*: The futures positions are collateralized with Treasury securities, money market funds, and T-Bill ETFs. The fund's total return is therefore a composite of (a) the performance of the underlying futures/index exposure and (b) interest income generated by this collateral pool. This two-part return structure means the fund's performance is not a pure, unlevered proxy for spot dollar movements alone — the interest-rate environment affecting the collateral assets contributes to total return independently of currency futures performance. The data provided does not include the relative weighting or performance contribution of each component.

**Data limitations bearing on this analysis**

- The data was collected via web search on 2026-08-16 and is not live/real-time.
- As noted above, the index description itself is inconsistent across sources (single USDX futures index vs. six-currency basket futures replication), and this analysis is not able to determine which is accurate from the data given.
- No figures are provided for individual currency weightings within the basket (if the multi-currency description applies), the allocation breakdown of the collateral pool, volatility or beta statistics, or an explicit tracking-error figure — so this analysis cannot characterize the tightness of the fund's tracking to its benchmark or its risk profile in quantitative terms.
- Separately reported figures elsewhere in the source data (e.g., dividend yield figures of 3.26% vs. 3.39%, and a YTD return figure dated 2026-03-20 alongside later, undated reporting of a multi-year DXY low) also reflect timing or source inconsistencies, though these pertain to performance rather than composition and are noted here only for completeness.

Given these gaps and the unresolved conflict over the index's underlying construction, this analysis describes the fund's structure as documented but stops short of characterizing its precise tracking behavior with confidence. No investment recommendation is offered, consistent with the scope of this analysis.
