**Distribution and yield.** The data supplied does confirm that EFA pays a distribution — it is not a zero-payout fund. However, the two cited sources disagree materially on the trailing-twelve-month yield: one figure is 3.36%, the other 2.75%, a gap of roughly 0.6 percentage points. The underlying data does not explain this discrepancy (e.g., whether one reflects a different as-of date, a different calculation methodology such as SEC 30-day yield versus trailing distributions, or a different price basis). Given this unresolved conflict, no single "current yield" figure can be stated with confidence from the data provided — both numbers should be treated as reported, not reconciled.

**Payment frequency.** EFA distributes semiannually. This is worth flagging only because it diverges from the frequency conventions the data notes for other funds referenced in the same source set (quarterly for QQQ/SCHD/AGG/VNQ, annual for GLD, monthly for UUP) — EFA sits outside all of those patterns.

**Tax-reporting structure.** No K-1/1099 distinction is mentioned for EFA in the data provided. (The data does flag that UUP, a separate fund referenced for comparison, issues a K-1 as a partnership structure — but nothing indicates EFA shares that structure, so absent contrary information EFA should be assumed to follow standard 1099 ETF reporting, though this is not explicitly confirmed in the data.)

**Data limitations bearing on this analysis.** The source material itself flags: the yield figures are unreconciled between sources (3.36% vs. 2.75%); a separate "average annual return" figure also shows minor inter-source variance (6.55% vs. 6.649%) with an unclear cause; the underlying research did not cross-check EFA's official fact sheet or index methodology documents; and the data is a search snapshot from 2026-08-17, not a live feed. Given the unresolved yield conflict, this profile should be read as identifying the discrepancy rather than resolving it.
